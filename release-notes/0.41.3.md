# A sweeter way to get Candy

Candy Browser 0.41.3 prepares Candy for Google Play distribution while keeping the complete 0.41
experience: gesture-first navigation, expressive Material design, Firefox extensions, strong ad
blocking, and open-source code.

## Install only what your device needs

- Google Play can deliver optimized app packages for your device instead of one universal download.
- GitHub releases remain available with the standard, ARM64, System WebView, and User CA variants.
- The standard GitHub APK and Play build use the same Candy application identity. The System WebView
  and User CA variants remain separate apps with their own identities.

Learn more in [signed release builds](https://github.com/sk2andy/candy-browser/blob/v0.41.3/README.md#signed-release-builds).

## Browse with your favorite Firefox add-ons

- Candy supports Firefox add-ons directly on Android.
- uBlock Origin is ready from the first launch, giving Candy strong ad and tracker blocking from the
  first browsing session.
- Installed add-ons stay under your control and can be managed from Candy's settings.

Learn more in [Firefox extension support](https://github.com/sk2andy/candy-browser/blob/v0.41.3/README.md#firefox-extension-support).

## Keep Candy yours

Candy remains open source. Private tabs stay memory-only, and the Play build uses the same privacy
boundaries and browser behavior as the standard Candy app.

Learn more in [privacy protection](https://github.com/sk2andy/candy-browser/blob/v0.41.3/docs/privacy-protection/README.md#topic-lookup).
