# 🎉 Firefox extensions arrive in Candy

Candy Browser 0.38.3 moves Android browsing to GeckoView and brings Mozilla-signed Firefox extensions
to Candy, with **uBlock Origin** and **I still don't care about cookies** ready in every fresh Gecko
profile.

## Bring Firefox extensions to Android

- GeckoView now powers Android pages and opens Candy to compatible Mozilla-signed Firefox
  extensions.
- Every fresh Gecko profile includes **uBlock Origin** and
  **I still don't care about cookies**, so ad blocking and calmer cookie consent work from the first
  page.
- Install more compatible Firefox extensions and manage their actions, popups, options, permissions,
  updates, and enabled state without leaving Candy.

Learn more in [Platform engines](https://github.com/sk2andy/candy-browser/blob/v0.38.3/docs/browsing/platform-engines.md#android-gecko-and-extension-invariants).

## Stay useful offline

- Connection failures now open a purpose-built offline surface instead of exposing the engine error
  page. Candy watches the validated network state in the background without sending connectivity
  probes.
- **Candy Circuit** turns the wait into a twelve-move rotation puzzle with circuits, combos, scores,
  and a session record.
- If the connection returns during a game, the board stays intact and Candy waits for you to press
  **Load page**. Without a started game, the page retries automatically.
- Missing destinations and real HTTP 404 responses receive a separate, focused recovery screen.

Learn more in [Runtime and navigation](https://github.com/sk2andy/candy-browser/blob/v0.38.3/docs/browsing/runtime-and-navigation.md#invariants).

## Find downloads and favorites quickly

![Candy Browser downloads with search and time filters](https://raw.githubusercontent.com/sk2andy/candy-browser/v0.38.3/docs/screenshots/downloads-overview.png)

- The browser menu now opens dedicated **Downloads** and **Favorites** libraries.
- Downloads combine Candy-owned transfers in one searchable, filterable view with live progress and
  confirmed cleanup.
- Favorites support local search, deletion with undo, and safe opening from regular or private
  browsing.

Learn more in [Downloads](https://github.com/sk2andy/candy-browser/blob/v0.38.3/docs/browsing/downloads.md#behavior) and [Favorites](https://github.com/sk2andy/candy-browser/blob/v0.38.3/docs/browsing/favorites.md#behavior-and-ownership).

## Richer Android browsing

- GeckoView brings stable picture in picture, browser-owned safe areas, and stronger session recovery
  to Candy.
- Link Peek gains configurable quick actions, Site Capsules accept custom and icon-pack artwork, and
  tabs can be duplicated from their menu.
- A responsive Candy search widget brings private and regular search directly to the launcher.

Learn more in [Picture in picture](https://github.com/sk2andy/candy-browser/blob/v0.38.3/docs/browsing/picture-in-picture.md#ownership-map).

## Private by design

Offline game state and network recovery stay in memory. Private tabs never persist favorites, and
the downloads library reads only files owned by Candy's Android package.
