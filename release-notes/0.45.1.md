# More languages, steadier everyday browsing

Candy Browser 0.45.1 expands the Android interface to 28 language choices and smooths out everyday
navigation: restore the address bar, complete Google sign-in, reach every dropdown option, and
return from video or background browsing with fewer interruptions.

## Candy in your language

Choose your language under **Settings → Browser → App language** or Android's per-app language
settings. Select **Follow device language** to follow your device. Changing the interface language keeps open tabs,
including private tabs, in place.

- New choices include Polish, Czech, Japanese, Korean, Thai, Vietnamese, and both Simplified and
  Traditional Chinese.
- More European languages include Norwegian Bokmål, Swedish, Danish, Dutch, Luxembourgish,
  Albanian, Bosnian, Bulgarian, Greek, Croatian, Macedonian, Romanian, Serbian, Slovenian, and Turkish.
- English, German, French, Portuguese, and Spanish remain available.

> New translations began as machine-assisted drafts, with browser labels, formatting, and
> security warnings reviewed. Native-speaker corrections are welcome.

Learn more about [app languages](https://github.com/sk2andy/candy-browser/blob/v0.45.1/docs/browsing/app-languages.md#supported-languages).

## Keep the address bar within reach

Manually restoring the parked address bar now keeps it available for editing instead of immediately
parking it again. The fix covers both Gecko and System WebView, including the reported YouTube
and Claude.ai interactions.

![Candy's floating address bar and its browser controls above a webpage](https://raw.githubusercontent.com/sk2andy/candy-browser/v0.45.1/docs/screenshots/candy-frosted-address-bar.png)

Learn more about [address controls](https://github.com/sk2andy/candy-browser/blob/v0.45.1/docs/browsing/address-actions-and-ui.md#gestures-and-actions).

## Follow links and return where you expect

- Google sign-in popups can complete their callback flow, including sign-in launched from Claude.ai.
- When no earlier page or originating tab remains, Back from your last or pinned tab returns to
  Candy's home screen. Tabs opened from Link Peek return to their surviving originating tab after
  page history is exhausted.
- Gecko dropdown dialogs scroll when the options exceed the available height, so the end of a
  long country list stays selectable in portrait and landscape.
- Gecko's resume and tab handoff keep the departing frame visible while a recreated page surface
  becomes ready. Temporary frames stay in memory, including during private browsing.
- Negative CSS top offsets remain unchanged by default, preserving intentional website layouts.

Learn more about [navigation and rendering](https://github.com/sk2andy/candy-browser/blob/v0.45.1/docs/browsing/runtime-and-navigation.md#navigation-paths).

## Leave fullscreen cleanly

Closing Candy Player fullscreen restores inline playback and the website's layout. YouTube's
Candy Player launcher stays below the video so site controls remain accessible. The extra
fullscreen minimize chevron has been removed.

YouTube picture-in-picture preserves the video's surrounding page layout across repeated Home
and return transitions instead of leaving the player collapsed.

> Candy Player remains experimental. Cross-origin iframe, canvas, and unsupported DRM players
> are outside its supported path; Android picture-in-picture requires active playback.

Learn more about [fullscreen and picture-in-picture](https://github.com/sk2andy/candy-browser/blob/v0.45.1/docs/browsing/picture-in-picture.md).

## Better Gecko diagnostics when you need them

Developer options now offer a separate, opt-in **Gecko logging** switch, editable native logging
modules, and manual export and deletion. Capture stays local and pauses while private tabs are open.
Sanitized App logging also includes bounded native crash information when Android makes it available.

> Raw Gecko logs can contain URLs, cookies, page content, and extension data. Review exported
> files before sharing. Parent-process capture does not cover every Gecko child-process event.

Learn more about [logging and privacy limits](https://github.com/sk2andy/candy-browser/blob/v0.45.1/docs/browsing/app-logging.md#raw-gecko-diagnostics).
