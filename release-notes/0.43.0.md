# Smoother browsing, fewer interruptions

Candy Browser 0.43.0 focuses on bug fixes. Links now reach the page or app you intended, System
WebView videos return to native fullscreen, and more sites fit the screen correctly. This release
also adds clearer site information and Gecko website push delivery.

## Links open where you expect

- Links shared from other apps now load as soon as the external preview opens, including after a
  fresh start.
- Tapped web links can open matching installed apps. **Open in app** finds suitable apps even when
  Android has no default handler; links without a safe match stay in Candy.

Learn more about [navigation and app handoffs](https://github.com/sk2andy/candy-browser/blob/v0.43.0/docs/browsing/runtime-and-navigation.md#navigation-paths).

## Fullscreen video and checkout fixes

- System WebView keeps its native fullscreen video view. Wide videos can switch to landscape without
  leaving audio playing behind a paused picture.
- Checkout popups retain their browser opener. On compatible System WebView providers, Candy enables
  Payment Request. Google Pay still depends on Google's app approval; GeckoView has no native Google
  Pay handoff.

Learn more about [web media and fullscreen](https://github.com/sk2andy/candy-browser/blob/v0.43.0/docs/browsing/runtime-and-navigation.md#web-media-fullscreen-and-picture-in-picture) and [Android engine support](https://github.com/sk2andy/candy-browser/blob/v0.43.0/docs/browsing/platform-engines.md#android-engine-selection).

## Site permissions and push

- Gecko website notification prompts and site controls work again. The address-bar connection badge
  opens one site sheet with connection details, Privacy X-Ray, and Permission Radar, even when no
  requests were blocked.
- Gecko website push can now receive messages through Mozilla Autopush without Google Play services.
  Battery restrictions may delay background delivery. System WebView has no website push integration.

Learn more about [site permissions](https://github.com/sk2andy/candy-browser/blob/v0.43.0/docs/privacy-protection/xray-permissions-and-maintenance.md#permission-radar) and [Gecko website push](https://github.com/sk2andy/candy-browser/blob/v0.43.0/docs/browsing/web-push.md).

## Edge-to-edge pages stay readable

Candy better protects top headers on edge-to-edge websites without shifting bottom-anchored
controls. Status-bar color and safe-area placement now follow changes within a page, including
single-page navigation.

Learn more about [Gecko safe-area controls](https://github.com/sk2andy/candy-browser/blob/v0.43.0/docs/browsing/runtime-and-navigation.md#gecko-css-safe-area-controls).
