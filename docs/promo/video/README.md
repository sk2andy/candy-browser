Regenerate the video from the repository-owned emulator captures:

```bash
python3 scripts/generate_reddit_promo.py
```

The generator requires Pillow and FFmpeg with `libx264` and AAC support. With the same fonts and toolchain,
rendering is deterministic: scene timing, motion, copy, synthesizer notes and pseudo-random percussion use
fixed inputs and seed. `--output`, `--theme` and `--poster` can isolate all generated files for test renders.
The original 112 BPM future-tech theme is generated by the script and does not use third-party samples.

Kinetic text, controlled scale-ins, focus-driven camera pans and alternating diagonal glow wipes connect the
scenes. Tab Switcher, Link Peek and Privacy X-Ray use live app footage. The Topping captures use the exact
published Topping scripts against deterministic mobile fixtures, which keeps the score-toggle and Hacker News
transformation reproducible. Reader Mode and Candy Trails use repository screenshots.

The 16:9 H.264/AAC output is intended for landscape product pages, social previews and presentations.
Important copy is burned into the video so the message remains understandable when playback starts muted.
