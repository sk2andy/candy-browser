# Reddit promo video

| Asset | Purpose |
| --- | --- |
| `candy-browser-reddit-4x5.mp4` | 22.6-second Reddit feed cut at 1080 × 1350 and 60 fps |
| `candy-browser-reddit-poster.jpg` | Upload poster and fallback thumbnail |
| `candy-browser-theme.wav` | Original procedural 112 BPM future-tech theme used by the cut |
| `source/tab-switcher-live.mp4` | API 36.1 emulator recording: swipe-up into the live tab switcher |
| `source/link-peek-live.mp4` | API 36.1 emulator recording: Link Peek preview and `+` tab commit |
| `source/privacy-xray-live.mp4` | API 36.1 emulator recording: Privacy X-Ray opening and scrolling |

Regenerate the video from the repository-owned emulator captures:

```bash
python3 scripts/generate_reddit_promo.py
```

The generator requires Pillow and FFmpeg with `libx264` and AAC support. With the same fonts and toolchain,
rendering is deterministic: scene timing, motion, copy, synthesizer notes and pseudo-random percussion use
fixed inputs and seed. `--output`, `--theme` and `--poster` can isolate all generated files for test renders.
The original 112 BPM future-tech theme is generated by the script and does not use third-party samples.
Kinetic text, controlled scale-ins and alternating diagonal glow wipes connect the scenes. Tab Switcher
gestures, Link Peek and Privacy X-Ray use live app footage. Reader Mode, Candy Trails, the three Tab
Switcher layouts, Profiles and Commands use repository screenshots.

The 4:5 H.264/AAC output follows Reddit's mobile-first aspect-ratio recommendation. Important copy is
burned into the video so the message remains understandable when playback starts muted.
