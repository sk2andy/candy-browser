Reader Studio bekommt neue Stimme

Ein neuer Beitrag im Feed. Tippe auf einen Eintrag und Candy öffnet den Inhalt direkt in der vertrauten Reader Studio Ansicht.

Lesefortschritt, Schrift und Vorlesen folgen bestehenden Reader-Mustern. Der Feed bleibt mit einem Schritt erreichbar.

Quelle ansehen ↗

ArtikelübergabeRSS-Inhalt priorisieren; wenn Artikelinhalt fehlt oder unvollständig ist, Reader-Extraktion der Quellseite versuchen.
Seite besuchen → RSS-Hinweis → Vorschau / abonnieren → Feed-Inbox → Beitrag → Reader Studio

Erster Umfang: Feed-Erkennung auf aktueller HTTP(S)-Seite, manuelle Bestätigung, lokales Abonnement, eine Beitragsliste und Öffnen im bestehenden Reader. Keine Konten, Synchronisierung, Push-Mitteilungen oder automatische Volltextsuche.

Offen: Abos pro Profil oder geräteweit? Aktualisierung nur beim Öffnen oder periodisch im Hintergrund? RSS-Volltext verwenden, Website-Artikel extrahieren oder beides mit Fallback? Private Tabs sollten keine Abos speichern; klären, ob dort Erkennung ganz verborgen bleibt.
