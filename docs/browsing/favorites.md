# Favorites

## Behavior and ownership

| Concern | Owner | Invariant |
| --- | --- | --- |
| Android collection | `FavoriteEntry`, `BrowsingLibraryRules`, `BrowserSessionStore` | Keep at most 100 local canonical HTTP(S) favorites. Favorites are global rather than profile-owned. Private page state never creates a persistent favorite; explicit library management may remove an existing one. |
| iOS collection | `BrowserViewModel`, `BrowserFavoritesRules` | Reflect the existing session-only favorite URL set; the library must not imply persistence that the iOS browser model does not provide yet. |
| Library entry point | `BrowserFeatureMenuRules`, `BrowserMainMenu`, `MainActivity` | The browser section of the ⋮ menu opens the Favorites library. |
| Search | `BrowsingFavoritesRules`, `FavoritesScreen`, `LibrarySearchBar`, `BrowserFavoritesRules`, `BrowserFavoritesSurface` | Filter locally and case-insensitively. Android searches stored title, URL and host, bounds input to 256 characters, discards invalid persisted URLs and collapses canonical duplicates. iOS searches its derived host title and URL. |
| Android presentation | `FavoriteFaviconRepository`, `FavoriteFaviconStore`, `FavoritesScreen` | Reuse a local regular-tab favicon when available. Otherwise fetch the favored page origin's `/favicon.ico` once while adding the favorite, following same-origin redirects only; never contact a third-party favicon service or fetch from the library screen. Keep the favorite-specific cache independent of tab lifetime and render a neutral title initial when no icon is available. Keep list rows unseparated and use the shared Material 3 SearchBar treatment. |
| Android new tab | `BrowserController`, `NewTabPage`, `NewTabFavoriteGrid` | Hide the favorites surface when the collection is empty or browsing is private. Present its localized Favorites heading inside a low-contrast outlined shelf, then show a generously inset four-column favicon grid with centered two-line labels and a neutral title-initial fallback, including blank-tab previews. Crop favorite and folder icons into circles. Size the shelf for at most five rows (20 entries), shrink it to the available height, and scroll further entries inside the shelf rather than scrolling the whole new-tab hero. This shelf is the default New Tab design; Site Capsules remain separately available with their existing behavior. Returning through the tab overview releases the non-interactive preview after the blank-tab content frame instead of waiting for a browser-engine frame that blank tabs never produce. |
| Favorite motion | `FavoriteAnimationSpeed`, `NewTabFavoriteLaunchOverlay`, `BrowserSettingsPage`, `BrowserSessionStore` | Long-press reorder lifts only a circular icon while its grid slot remains as a faded placeholder; adjacent slots animate to show the destination. Opening a favorite animates its circular icon through a short Candy-colored arc into the search hero. The Browser settings provide Relaxed, Normal, and Fast launch speeds; the animation switch restores immediate navigation. |
| HTML bookmark import | `FavoriteBookmarkImportReader`, `FavoriteBookmarkImportRules`, `FavoriteBookmarksImporter`, `BrowserSettingsPage` | The Favorite settings accept bounded UTF-8 Netscape bookmark HTML exported by other browsers. Flatten folders, decode HTML entities, retain only credential-free HTTP(S) URLs, preserve existing favorites, collapse canonical duplicates, and add imported entries until the global 100-favorite limit is reached. Parsing runs off the main thread. |
| Delete and undo | `FavoritesActivity`, `FavoriteUndoRules`, `FavoritesScreen`, `BrowserFavoritesSurface` | Delete one favorite and offer undo. Android commits library deletion off-main before updating the list and showing its Snackbar; restore the exact previous library including folders, sibling order and parent IDs only while the mutation revision is still current. Rename, reorder, move and icon changes invalidate older undo actions. Every manager edit commits the complete library off-main with an expected-current snapshot before publishing UI state. iOS provides the equivalent timed bottom banner for its session collection. |
| Open | `FavoritesActivityContract`, `BrowserController.openFavorite` | Validate the selected URL again at the browser boundary. A selection made from private browsing opens in a regular tab so persistent library data is not navigated inside a private session. |
| Refresh | `MainActivity`, `BrowserController.reloadFavorites` | Reload controller state whenever the library activity returns, including Back after a deletion. Increment the mutation revision so an older browser Snackbar cannot overwrite library changes. |
| Folder hierarchy | `FavoriteLibraryEntry`, `BrowsingFavoritesRules`, `BrowserSessionStore`, `FavoritesScreen` | Favorites may live at root or in arbitrarily deep folders. Folder children are ordered independently from their parent siblings. Moving an entry into a folder and selecting the folder-arrow-up parent action preserve the entry and its order. |
| Favorite management | `FavoritesActivity`, `FavoritesScreen` | The library supports long-press/drag reorder and accessible Move earlier/Move later menu actions, rename, named folder creation at the current location, and moving favorites or whole folders. Move destinations exclude the selected folder and its descendants. In the move dialog, the folder-arrow-up action immediately moves the selection to the parent level; selecting a folder then Move here moves it inside that folder. Back and the list parent action navigate toward root. Folder deletion is not exposed. Search includes titles and URLs throughout the hierarchy. Empty folders stay empty instead of showing root favorites. |
| Folder presentation | `FavoritesScreen`, `NewTabFavoriteGrid` | A folder may have an emoji or user-provided icon. The Folder icon menu accepts an optional emoji, Choose image, or Use favicon preview. `FavoriteFolderIconStore` decodes uploads off-main, rejects images above 8 MiB or dimensions above 8192 pixels, samples to at most 256 pixels, and atomically stores PNG copies in app-private `noBackupFilesDir/favorite_folder_icons`. Provider permissions and source-file lifetime are not required after import. Without a custom icon, show a deterministic 2×2 mosaic of the first four descendant favicons (depth-first in sibling order) in library and new-tab previews. Opening a folder animates into its children; the labeled `mdi:folder-arrow-up` parent action is shown only below root. |
