# RSS settings artwork

Generated with the built-in ImageGen tool for RSS settings header. Used the existing Candy settings
artwork as visual direction; the image is monochrome because Compose recolors it for the active
theme.

> Minimal monochrome grayscale settings header illustration, wide 3:2 composition, browser RSS feeds
> flowing into Reader Studio: three overlapping clean article cards, simple broadcast arcs, one open
> book card, tiny notification dot. Restrained polished Candy Browser settings artwork, rounded
> geometric shapes, paper grain, charcoal foreground, soft gray secondary shapes on warm white. No
> text, no logos, no UI screenshot, no color. Generous white space; forms centered and readable in
> wide crop.

The saved asset is `shared/src/commonMain/composeResources/drawable/settings_approved_rss.png`
(1536 × 1024). Its complete image is used as the source window, with no crop or pixel edits.
