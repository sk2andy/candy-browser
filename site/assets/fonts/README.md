# Website fonts

`Nunito-wght.ttf` and `Nunito-OFL.txt` come from the official Google Fonts repository at commit
`8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`:

- source: `ofl/nunito/Nunito[wght].ttf`
- license: SIL Open Font License 1.1 (`ofl/nunito/OFL.txt`)
- font SHA-256: `bb55a5ca5c2042335b3991af27c4d0705d0ef41cac6164ac737fd8f2a1e85207`

The website serves the font locally and does not contact Google Fonts at runtime.

`RobotoFlex-latin.woff2` is the Latin variable-font subset delivered by Google Fonts for
Roboto Flex v30. `RobotoFlex-OFL.txt` comes from the official Google Fonts repository:

- source family: `ofl/robotoflex`
- license: SIL Open Font License 1.1 (`ofl/robotoflex/OFL.txt`)
- font SHA-256: `b80f7198cce0a739fd1a6b39430f9da48ae29d4d4c32d5097ac1280b401a37f8`

Roboto Flex is served locally as the body and UI font. Nunito remains limited to expressive
display headlines.
